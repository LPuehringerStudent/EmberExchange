Project Overview

A trading game for digital stoves

The project combines collection, trading, price tracking, chat, and multiplayer games in one web app

  • Players start with Coal, open lootboxes, and receive random stove collectibles
  • Every stove has rarity, heat, collection value, and market history

Forge And Collections

The Forge

Players can turn extra stoves into upgrades, Sparks, and collection progress

  • Six stoves of one rarity can become one stove of the next rarity
  • Unwanted stoves can be salvaged into Sparks
  • Collections reward players for completing themed stove sets
Mini-Games

Mini-Games

Poker, Blackjack, and Roulette let players use Coal in live game rooms

Poker

Roulette

Technology

Full-stack implementation

The project includes database logic, authentication, real-time communication, security, and deployment

Angular Frontend

Standalone components, routing, services, signals, and a polished responsive interface

Express Backend

TypeScript REST API with service layers for players, stoves, marketplace, chat, and games

PostgreSQL

Persistent storage for accounts, inventory, trades, prices, messages, and game data

WebSockets

Live chat, game rooms, read receipts, and real-time multiplayer state

Security

Sessions, rate limiting, Turnstile, IP bans, honeypots, request logs, and admin protections

Deployment

Production-ready build served through Render with health checks and scheduled jobs
