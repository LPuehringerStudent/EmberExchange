# Epic 8: First Impressions & Onboarding

**Source:** Teacher feedback + award presentability  
**Priority:** P0  
**Sprint:** Sprint 6 (final graded sprint)  
**Total Estimate:** ~7.5h

---

## Goal

Address the core concern that EmberExchange is overwhelming for non-gamers and first-time visitors. Keep the existing depth — do not remove features — but add a "shallow end of the pool" so judges and new users can understand the site within 30 seconds.

---

## Guiding Principles

1. **Optional, never blocking.** Onboarding must be dismissible. Power users should not feel slowed down.
2. **Explain in plain English.** No jargon. "Rarity" means "how rare this stove is." "Pity" means "guaranteed legendary after enough bad luck."
3. **Show, don't tell.** Screenshots, animations, and previews beat paragraphs.
4. **Polish over quantity.** One smooth animation is worth three half-finished features.

## Definition of Done (Epic Level)

- [ ] A first-time visitor can understand what EmberExchange is in under 30 seconds without registering.
- [ ] A new user who registers sees a helpful, dismissible tour of the core loop.
- [ ] Every confusing game mechanic (Rarity, Heat, Pity, Sparks, Forgery) has a contextual explanation.
- [ ] The landing page and `/how-it-works` page look polished at 375px, 768px, and 1440px.
- [ ] No new console warnings or TypeScript errors.
- [ ] All new UI text is in plain English — no unexplained jargon.
