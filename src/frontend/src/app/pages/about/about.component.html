What is EmberExchange?

A full-stack web application built as a virtual economy and collection game.

Collect

Open lootboxes to discover unique stoves across multiple rarities.

Trade

Buy, sell, and trade stoves in a player-driven coin economy.

Upgrade

Merge six stoves of the same rarity in the Forge to forge rarer ones.

Play

Join real-time Poker, Blackjack, and Roulette rooms.

Tech Stack

Built with modern, battle-tested technologies.

Angular 21

Standalone components, signals-based reactivity, lazy-loaded routes.

Tailwind CSS v4

Utility-first styling with custom design tokens and dark ember theme.

Express.js 5.2

TypeScript 5.9 backend with 37 REST API routers.

PostgreSQL

Neon serverless Postgres with pg connection pooling.

WebSocket

Real-time game rooms and chat via the ws library.

Swagger / OpenAPI

Interactive API docs auto-generated from JSDoc comments.

Jest

Sequential backend test suites with ts-jest.

Render

Auto-deploy from main branch to a Render Web Service.

System Architecture

From the browser to the database.

Security Highlights

Multiple layers of protection for players and data.

Rate limiting on auth, registration, and 2FA
Cloudflare Turnstile bot challenge
Behavior guard & honeypot decoys
IP banning via BannedIP table
Prototype pollution protection
CORS whitelist + Helmet headers
Request & security event logging
WebSocket hardening (IP limits, payload caps)
