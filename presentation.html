Why we built it

  • Real product, not a demo. Deployed, secured, and used by real players.
  • Learn by doing. We tackled economy design, real-time systems, security, and devops.
  • Competition drives fun. Leaderboards and rarity create real player engagement.
  • Full-stack from scratch. Angular + Node + PostgreSQL + WebSockets.
  • Security first. Multiple anti-bot layers, audit events, and admin tooling.
  • Live deployment. Auto-deployed to Render from GitHub.
