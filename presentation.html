What is EmberExchange?

EmberExchange is a full-stack web application built as a virtual economy and collection game.

  • Players collect unique stoves with different rarities
  • Open lootboxes with weighted drop rates
  • Trade stoves on a marketplace with real coin economy
  • Track price history, ownership chains & stats
  • Play real-time Poker, Blackjack & Roulette

Core Features

Lootbox System

  • Multiple lootbox types (Standard, Dragon, Legendary, Winter...)
  • Weighted drop rates per rarity
  • Pity system guarantees rare drops
  • Animated chest opening experience

Marketplace

  • Create listings with custom prices
  • Price history charts
  • Trade offers between players
  • Coin transaction ledger

Forgery (The Forge)

  • Rarity upgrade mechanics
  • Forgeable rarity recipes

Quests & Progression

  • Daily & weekly quests
  • XP & coin rewards
  • Achievement engine

Real-Time Multiplayer Games

Poker

  • Texas Hold'em
  • Blinds & betting rounds
  • Side pots & all-in logic
  • Hand evaluation

Blackjack

  • Bet, Hit, Stand, Double, Split
  • Dealer AI (hits soft 17)

Roulette

Backend Technologies

Express.js 5.2

  • REST API routers under /api
  • 37 routers covering all domains
  • Middleware pipeline (auth, rate limits, CORS, Helmet)

Database Layer

  • PostgreSQL with pg pool
  • Programmatic schema management
  • Unit transaction pattern
// Unit transaction pattern
const unit = await Unit.create(false);
try {
  const service = new ListingService(unit);
  const result = await service.createListing(data);
  await unit.complete(true);
  return result;
} catch (err) {
  await unit.complete(false);
  throw err;
}

Database Architecture

  • PostgreSQL hosted on Neon (serverless Postgres)
  • Schema managed programmatically via DB.ensureTablesCreated()
  • Snake-case columns in DB → camelCase in TypeScript via COLUMN_MAP
  • 50+ services, one per domain (Listing, Trade, Player, Quest, etc.)
  • Connection pooling via pg Pool

Hosting & Deployment

Render Web Service

  • Auto-deploy from main branch

  • Build: backend + Angular build
  • Start: node dist/backend/app.js
  • Health check: GET /api/health

External Services

  • Neon — PostgreSQL database
  • Resend — transactional emails
  • Cloudflare Turnstile — bot protection
  • Google & GitHub OAuth

Environment Secrets

All sensitive values are stored in the Render dashboard environment variables:

  • DATABASE_URL
  • SESSION_SECRET
  • OAuth credentials
  • Resend API key
  • Turnstile keys
  • Anti-bot configuration

Secrets are never committed; .envRender is gitignored.
